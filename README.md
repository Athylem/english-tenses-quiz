# Tenses Revision Test — entraînement interactif

Site d'entraînement aux temps anglais (present simple/continuous, past, present perfect, past perfect, futur),
d'après la fiche *Tenses Revision Test*. On écrit la réponse, le site corrige et explique pourquoi.
